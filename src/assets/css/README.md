# طبقات الأنماط (CSS)

كل ملف هنا **طبقة** مستقلّة، وترتيب الاستيراد في `src/main.js` هو ترتيب الـ cascade:
عند تساوي الأسبقية (specificity) تفوز الطبقة المتأخّرة.

| # | الملف | الدور |
|---|-------|-------|
| 1 | `style.css` | الأساس: المتغيّرات (`:root`)، الـ reset، RTL، والتنسيق العام |
| 2 | `theme.css` | الثيم الفاتح/الغامق + متغيّر ارتفاع الشريط `--nav-h` |
| 3 | `calc-ops.css` | تخطيط صفحتَي الحاسبة والهندسة + شبكة النتائج واللوحات |
| 4 | `components.css` | مكوّنات الموقع المشتركة (الهيدر، الفوتر، البطاقات…) |
| 5 | `design.css` | طبقة اللمسة الأخيرة: تصقل الطبقات السابقة |

> ⚠️ **لا تُغيّر ترتيب الاستيراد في `src/main.js`.** هناك 117 مُحدِّدًا مشتركًا بين
> الملفات تُحلّ بالترتيب لا بالأسبقية، فأي إعادة ترتيب تُغيّر الشكل النهائي.

هذه الملفات تعالجها Vite وتُجمع في ملف واحد مُبصَّم باسم يحمل `hash`
(`assets/index-*.css`)، لذلك لا حاجة لأي إجراء يدوي لكسر الكاش عند النشر.
