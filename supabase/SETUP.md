# ⚙️ تشغيل قاعدة البيانات (Supabase) — خطوة بخطوة

> كل ما يلزم الموقع جاهز في الكود. المتبقي فقط: إنشاء مشروعك وربطه به.
> الوقت المقدَّر: **5 دقائق** — والمشروع المجاني يكفي بالكامل.

---

## 1) أنشئ المشروع

1. اذهب إلى <https://supabase.com> وسجّل (يمكن Google/GitHub).
2. **New project**:
   - اسم organisation وأي اسم للمشروع (مثل `hasibati`).
   - كلمة مرور قاعدة البيانات (Database Password) — احفظها في مدير كلمات المرور.
   - اختر منطقة قريبة منك (مثل `eu-central-1`).
   - انقر **Create new project** وانتظر ~دقيقتين حتى يجهز.

## 2) شغّل مخطط قاعدة البيانات (الأهم ✅)

1. في القائمة الجانبية افتح **SQL Editor** ← *New query*.
2. افتح ملف `supabase/schema.sql` من هذا المشروع،
   انسخه كاملاً (أو ارفعه من زر التحميل) والصقه في المحرر.
3. اضغط **Run** — ستظهر رسالة نجاح.
4. (اختياري) تحقق: **Table Editor** ← ستجد الجداول الثلاثة:
   `profiles` و `contact_messages` و `tool_history`.

> المخطط ينشئ ثلاث جداول مع حماية RLS كاملة:
> كل مستخدم يرى بياناته فقط، ورسائل التواصل يراها أنت فقط من لوحة Supabase.

## 3) الصق المفاتيح في الموقع

1. من القائمة الجانبية افتح **Settings ← API** (أو **Project Settings ← API**).
2. انسخ **Project URL** (مثل `https://xxxx.supabase.co`).
3. انسخ **anon / public** key (المفتاح العام — آمن للنشر في المتصفح).
4. افتح ملف `js/supabase-config.js` في مشروعك واستبدل الخطين الأخيرين:

```js
const SUPABASE_URL = 'https://xxxx.supabase.co';
const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```

5. حدّث الصفحة — ستظهر رسالة "بقعة" عند تسجيل الدخول فوراً.

## 4) اسمح للروابط المحلية (مهم للتجربة)

1. **Authentication ← URL Configuration**.
2. في **Redirect URLs** أضف:
   - `http://127.0.0.1:8377/**`  ← المعاينة المحلية
   - `http://localhost:8377/**`   ← اختياري
   - ومجالك النهائي لاحقاً (مثل `https://hasibati.com/**`)
3. وفي **Site URL** ضع `http://127.0.0.1:8377` (أو مجالك لاحقاً).

## 5) (اختياري) تسجيل فوري بدون تأكيد البريد

- **Authentication ← Providers ← Email** وأزل التحقق من *"Confirm email"*.
- عندها يُنشأ الحساب ويدخل المستخدم مباشرةً.
- اتركه مفعّلاً إن أردت البقاء آمناً (سيصل رابط تأكيد بالبريد).

---

## ماذا سيعمل تلقائياً بعد الربط؟

| الميزة | التخزين |
|---|---|
| إنشاء حساب / تسجيل دخول / استعادة كلمة المرور | `auth.users` (Supabase) |
| الاسم الظاهر في شريط التنقل | `profiles` (يُنشأ تلقائياً) |
| كل عملية في الحاسبة / الأنظمة / الهندسة (للمسجّلين) | `tool_history` |
| رسائل نموذج "تواصل معنا" | `contact_messages` |

وداعاً لقاعدة البيانات الوهمية — كل شيء حقيقي ومحميّ بين المتصفح والسحابة.

## ملاحظات أمان

- المفتاح `anon` **مصمَّم** ليظهر في المتصفح؛ الحماية الكاملة من سياسات RLS داخل الجداول (موجودة في المخطط).
- لا تضع أبداً `service_role` key في المتصفح.
- كلمة مرور قاعدة البيانات تُستخدم فقط من لوحة الـ SQL، لا علاقة لها بالموقع.
